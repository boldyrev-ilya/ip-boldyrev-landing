# Лендинг ИП

Отдельный лендинг ИП об автоматизации работы нотариальных контор.

Основной домен: `https://notary-it.pro/`.

## Локальный адрес

`http://localhost:3001/`

Порт `3001` закреплён за этим проектом. Сайт нотариуса работает отдельно на
`3000`, магазин в Таиланде — отдельно на `3002`.

## Запуск

На macOS можно дважды нажать `start-ip-landing.command`.

Из терминала:

```bash
npm run dev
```

Команда запуска всегда использует `localhost:3001`.
Она не удаляет файлы: при обнаружении устаревшего служебного замка запуск
останавливается и показывает предупреждение.

## Проверка сборки

```bash
npm run build
```

Проект требует Node.js `22.13.0` или новее.
